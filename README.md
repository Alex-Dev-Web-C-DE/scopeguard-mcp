\# ScopeGuard MCP



MCP server for \*\*ScopeGuard\*\* — sanctions scope monitoring with webhook alerts.



Register entities, countries, or industries and get webhook notifications when new sanctions hit your watch list.



\## Tools



\- `register\_scope` — Register a new scope (entity + webhook URL)

\- `list\_scopes` — List all registered scopes

\- `check\_sanctions` — Screen a name against OFAC + UK + EU + UN sanctions lists

\- `delete\_scope` — Remove a scope by ID



\## Install



```bash

npm install -g scopeguard-mcp
